# Bộ script Tử vi – Bát tự – Phong thủy (dùng cho skill tu-vi-bat-tu-phong-thuy-v3)

Nhánh này chỉ chứa mã và tài liệu mà skill tự tải về khi chạy. Không chứa dữ liệu cá nhân.

- `tvbt/*.py`: các script tính toán (chương trình chính `tvbt.py`, lệnh nâng cao qua `nc.py`, dò giờ sinh qua `giosinh.py`).
- `tvbt/docs/*.md`: hướng dẫn luận theo từng môn.
- `tvbt/kiemtra.py`: tự kiểm tra toàn bộ, phải in `TỰ KIỂM TRA TOÀN BỘ: ĐẠT`.
- `MANIFEST.sha256`: mã kiểm tra từng file.

Cần Python 3 và `pip install lunar-python==1.4.8`.
